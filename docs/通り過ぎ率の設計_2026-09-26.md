**#25「立ち寄り率・滞在時間」を出すための設計。今夜は設計だけで、本番には入れない**
（進行役の判断：23:04 に入れた1周の直しを、まだ一度も本番で見ていないため。
明日の実測より前に、未確認の変更を重ねない）。

## いま取れているもの

`visit` の記録に、9/26 00:53 から次が入っている。

| 欄 | 中身 |
|---|---|
| `who` | 顔で分かった人（5分以下の滞在は除いてある） |
| `stay` | 人ごとの滞在の秒数 |
| `seen` | 人が居たことは確か（誰かは分からなくてもよい） |
| `face_span` | 顔が写っていた長さ（秒） |
| `passed_by` | `face_span` が 30秒（`MIN_PRESENCE`）未満 |

**2.4.1（いまの記録で分かるか）の答え：分かる欄はある。ただしそのままでは使えない。**
理由が2つある。

## 問題1：`passed_by` は滞在ごとで、人ごとではない

`face_span` は**その滞在で最初に顔が写ってから、最後に写るまで**である。
そして滞在は **30分（`VISIT_MERGE_GAP`）以内の出入りを1つにまとめる**。
共用キッチンでは誰かしらが通るので、**滞在は何人ぶんもまとまる。**

実際の3件（9/26）：

| 時刻 | `face_span` | `passed_by` | 人ごとの滞在 |
|---|---|---|---|
| 19:22 | 2358秒（39分） | False | p16:2585 |
| 20:40 | 3926秒（65分） | False | p16:2781 / p01:4176 / p06:2168 |
| 21:37 | 1784秒（30分） | False | p02:2103 |

**3件すべて False。**当然で、複数人がまとまった滞在の `face_span` が30秒を切ることはない。
**通り過ぎた人が居ても、同じ滞在に長居した人が1人居れば False になる。**

> `passed_by` は**「この滞在に、ひとりも長居しなかったか」**を測っている。
> **「この人は通り過ぎたか」ではない。**

### 直し方（人ごとに測る）

人ごとの最初と最後は**すでに状態に持っている**。

- `st["visit_of"][pid]` … その人の滞在の始まり
- `st["seen_at"][pid]` … その人を最後に見た時刻

だから人ごとの長さは `seen_at[pid] − visit_of[pid]` で出る。
`visit` の記録に **`spans: {pid: 秒}`** を足せばよい（`stay` とは別に持つ。下記の問題2のため）。

## 問題2：いまの `stay` は「比べた時刻まで」で測っている

```python
def _person_stay(st, pid, now):
    v = (st.get("visit_of") or {}).get(pid)
    return (now - float(v)) if v else 0.0      # ← now は「比べた時刻」
```

`now` は**見回りで前後を比べた時刻**である。その人が30分前に帰っていても、
**帰ったあとの時間まで滞在に足されている。**

しかも 1周ぜんぶ回す形（2026-09-26）にしたので、**1周が長引くほど滞在が伸びる。**
**滞在時間の数字は、装置の見回りの都合で動く。**これは #25 に直に効く。

直しは1行：`now` ではなく `st["seen_at"][pid]` を使う。
**ただし今夜は押さない。**明日の実測（2.6.3）で1周の長さを測ったあと、
**同じ日の記録で新旧どちらの数字も出して、差を見せてから**入れ替える。

## 分母をどうするか（A の案への返し）

A の案：**`face_span` が0の滞在は分母から外す**（顔が1枚も取れていないので、
通り過ぎたのか長居したのか分からない）。

**外すことには反対する。理由は、外す集団がまさに測りたい集団だからである。**

- 顔が取れないのは、**速く通り過ぎた人**に最も起きやすい（9/24 の記録：
  「見たい場面ほど顔が撮れない」）
- それを分母から外すと、**通り過ぎた人だけが消えた分母**で通り過ぎ率を出すことになる。
  **率は必ず低く出る。**
- 9/10〜15 の「誰か分かった率 100%」と**同じ型の誤り**である
  （記録に残っていないものを、無かったことにして割る）

### 代わりの形：3つに分けて、3つとも出す

| 区分 | 条件 | 意味 |
|---|---|---|
| **立ち寄り** | 人ごとの長さ ≧ 30秒 | 留まった |
| **通り過ぎ** | 人ごとの長さ < 30秒 | 通った |
| **不明** | 顔が0枚（`seen` は True） | **人は居たが、どちらとも言えない** |

**通り過ぎ率は「通り過ぎ ÷（立ち寄り＋通り過ぎ）」と「通り過ぎ ÷ 全部」の両方を出す。**
前者は上限、後者は下限になる。**不明の件数を必ず並べて書く。**
不明が多ければ、率そのものではなく**「幅」として報告する**。

## 決める必要があること（本人・A と）

1. **30秒（`MIN_PRESENCE`）を通り過ぎの線にしてよいか。**いまの値はもともと
   別の用途（人が居たと認める線）のもの。#25 の線として妥当かは別の話
2. **9/26 00:53 より前は出せない**（`face_span` が無い）。観察期の通り過ぎ率は
   **9/26 からの分だけ**になる。CSV に注記を入れる
3. 上の「不明」を、**人ごとに数えられるか**。顔が0枚なら人の番号が無いので、
   **件数は滞在単位でしか数えられない**（人数は分からない）。ここは
   「不明な滞在が何件あったか」までしか言えない
