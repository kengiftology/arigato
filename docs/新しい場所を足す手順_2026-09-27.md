# 新しい場所を足す手順（2026-09-27）

**この手順書でできること：新しい場所に装置を1台立ち上げる。**
所要 **半日**（うち、人が現場に居るのは **30分ほど**）。

**できないこと：2か所を同時に動かすこと。**
いまの装置は「場所は1つ」という前提で組まれている（`docs/2か所目を足せるか_2026-09-27.md`）。
**2台目を動かすには、先に「場所」という入れ物を作る必要がある**（2〜3日の作り直し）。
この手順書は**1か所を新しく立ち上げる／置き直す**ためのものである。

---

## 大事なこと（先に読む。ここを外すと丸一日失う）

1. **見本の写真は、見回りとまったく同じ道順で撮る。**
   手でカメラを向けて撮ったもの、アプリの画面から撮ったものは**使えない**。
   見回りは毎回「入り口 → その向き」と振り、**覚えた補正を足した向き**へ行く。
   道順が違うと**画角が 180〜230px ずれ、永久に合わない。**（9/26・9/27 に2度やった）
2. **カメラが「止まった」と言っても、映像は9〜10秒遅れて入れ替わる。**
   止まった直後に撮ると**振り向く途中の景色**が写る。**必ず測ってから決める。**
3. **「その場所が写っているか」を決められるのは人だけ。**
   機械は「この見本は間違っている」と言えない。**間違った見本を登録すると、
   そこから先ずっと『合っている』と出続けて、誰も気づけない。**
4. **他所で決めた数字を流用しない。**帯も線も向きも、**その場所で測る。**
5. **決めた数字は、いつ・どうやって決めたかと一緒に残す**（`decided`）。
   手で決めた数字は古くなる。古くなったことは、数字を見ても分からない。

## 用意するもの

| もの | 備考 |
|---|---|
| Tapo のカメラ（TC71） | 首振り（PTZ）ができるもの。**天井近くに逆さ吊り** |
| つなぎっぱなしの PC | 橋渡しを動かす。落ちると記録が全部止まる |
| C3（顔の画面） | 無くても記録は取れる。表情を見せるなら要る |
| Wi-Fi | カメラと PC が同じ網に居ること |
| 鍵 | `SPIRIT_KEY`（送信）・`ANTHROPIC_API_KEY`（判定）。**装置用に分けるのが安全** |

## 手順

### 1. カメラを付ける（人・20分）

- **天井近くに、逆さ吊りで。**見たい面（流し・台・コンロ）が上から見下ろせる位置
- **人が入ってくる方向**も振れば見える位置に（顔を撮るため）
- Tapo アプリで、カメラの**合言葉**と ONVIF（ポート 2020）を有効にする

### 2. 橋渡しを立てる（機械・10分）

`bridge/sweep.py` の先頭を、その場所のカメラに合わせて直す。

```python
HOST, PORT = "192.168.0.230", 2020      # ← カメラのアドレス
USER, PWD  = "thankU", "39Kitchen"      # ← カメラの合言葉
HOME = (0.7, 0.4)                       # ← 待つ向き（手順3で決める）
```

橋渡しを、**会話やターミナルの裏ではなく、OS のタスクとして**動かす。
（9/24、会話の裏で動かしていて、会話が終わると同時に止まり**1時間51分**記録が消えた）

Windows なら `.arigato/bridge_run.ps1` を5分おきのタスクにする。**動いているかを見て、
居なければ起こし直す**形にすること。

### 3. 待つ向きを決める（人・5分）

**人が入ってくる所が写る向き。**ここで顔を撮る。
Tapo の画面で向きを動かし、良い向きの数値（よこ／たて）を控える。

### 4. 映像の遅れを測る（機械・3分）★ 飛ばさない

```bash
python scripts/aim_settle.py <よこ> <たて>      # いちばん大きく振る向きで
```

出た秒数＋2秒を `bridge/tapo_bridge.py` の `SETTLE_AFTER_MOVE` に入れる。
**キッチンでは 9〜10秒だった**（カメラ自身は 4.2秒で「止まった」と返す）。

### 5. 区画を決める（人・10分）

**見たい場所を選ぶ。**1か所につき1つの向き。
（テーブルとコンロのように、**1枚に2か所写るなら、向きは1つで切り出しを2つ**にできる）

Tapo の画面で向きを動かし、**その場所が大きく写る向き**を選んで数値を控える。
区画は**3〜5個**が目安。増やすほど1周が長くなる（4区画で約130秒）。

### 6. 見本を撮る（機械・区画あたり1分）

```bash
python scripts/zone_shoot.py ./見本 水切り -0.80 -0.90 テーブル -0.50 0.00
```

**見回りと同じ道順で撮る。**補正は自動で足される。

### 7. 撮った写真を、人が目で見て確かめる（人・5分）★ ここは機械に任せられない

1枚ずつ見て、**「その場所が写っているか」**だけ答える。

- 狙った場所が画面に入っているか（**9/27、コンロが画面から外れていた。本人が見て分かった**）
- 人や一時的な物が写り込んでいないか
- 暗すぎないか

**写っていなければ、向きを変えて撮り直す**（手順5へ戻る）。

### 8. 見本を登録する（機械・1分）

```bash
python scripts/zone_shoot.py ./見本 --register 水切り ./見本/水切り.jpg
```

### 9. 帯と線を測る（機械・3分）

```bash
python scripts/zone_lines.py ./見本
```

**ほかの区画と紛れない帯**を選ぶ。線は、**同じ場所を時刻を変えて何枚か撮り**、
**同じ向きどうしの確かさがどこまで下がるか**を見てから、**その下限より下**に置く。
（キッチン：同じ向き 0.088〜0.28／違う向き 最大 0.062 → **線 0.08 ＋ ずれ60px の2段**）

**確かさだけでは足りない。**確かさは「同じ景色か」を、ずれは「離れすぎていないか」を答える。
**別々の問いなので両方要る**（9/22、確かさを見ずにずれだけで見ていて、壁を写した1枚を通した）。

### 10. 設定に書く（機械・10分）

`server/routers/spirit.py` の `ZONE_CFG_DEFAULT` に、区画ごとに書く。

```python
"水切り": {
    "id": "rack", "active": True, "pose": "-0.80_-0.90",
    "aim": {"ref": "spirit/zoneref/rack.jpg", "band": [0.0, 1.0],
            "min_conf": 0.08, "max_shift": 60},
    "crop": {"box": [0.35, 0.15, 0.82, 1.0], "rotate": 180, "hide_from": None},
    "ask": {"scene": "写真は…を天井近くから写したものです。",
            "fixtures": "…は備え付けです。数えません。",
            "empty_q": "…はありますか？ JSONだけで答えてください：…"},
    "rule": {"kind": "change"},
    "decided": "2026-09-27 本人が写真から向きを選択。線は当日の実測（同じ向き…／違う向き…）",
},
```

**`decided` は必須。**空で通してはいけない。

### 11. 切り出しを決める（人が選ぶ・5分）

**その場所だけが入るように切る。**床・冷蔵庫・隣の区画が入ると、そこの物を数えてしまう。
候補を2案つくって**人に選んでもらう**（9/27 はそうした）。

### 12. 動くことを確かめる（機械・人が来てから）

```bash
python scripts/zone_check.py 3
```

- **区画ごとに「比べられた」が1件以上あるか。**0件なら、その区画は**死んでいる**
- 飛ばした理由が `view_mismatch` なら、**見本と実際の画角がずれている**（手順6へ戻る）
- **1周の時間**が見込みどおりか

**押したあとは、必ず実物を1回流す。**テストが通ったことは、動くことの証明ではない
（9/27、テストは通ったのに AI の呼び出しが4分間すべて落ちていた）。

## うまくいかないとき（すべて 2026-09-26〜27 に実際に起きたもの）

| 症状 | 原因 | 直し |
|---|---|---|
| 区画が全部「違う景色」で飛ばされる | 見回りが**振り向く途中**を撮っている | 手順4（待ち時間を実測する） |
| 1つの区画だけ合わない | その見本だけ**別の道順で撮った** | その区画だけ手順6〜8をやり直す |
| ずれ0pxなのに弾かれる | **線が厳しすぎる**（他所の値の流用） | 手順9（その場所で測り直す） |
| 1枚の写真が全区画の答えになる | 「最後に合った1枚」を**全区画で共有**していた | いまは見本ごとに分けてある |
| 記録は出ているのに判定が0件 | 見回りの向きが**1つしかない** | いまは向きで順ぐりに回る |
| 誰がやったか結びつかない | 1回の滞在で**1区画しか見ていない** | いまは**滞在のあいだに1周ぜんぶ回す** |
