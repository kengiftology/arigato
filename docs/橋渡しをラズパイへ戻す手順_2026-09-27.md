# 橋渡しをラズパイへ戻す手順（2026-09-27 作成・**実施は 9/29 の見切りのあと**）

いま橋渡しは**ノートPC**で動いている。9週間の観察を「ノートを家に置いたままにする」前提に
することが弱いので、ラズパイへ戻したい。**ただし急がない。**下の「やらない条件」を先に読む。

## いちばん大事なこと：**試してから切り替える、ができない**

2026-09-27 に分かった。**カメラは映像の接続を1本しか許さない。**
PC の橋渡しが動いている間、ラズパイから映像を取ろうとすると `Operation not permitted` で断られる。

> **つまり「ラズパイで動くことを確かめてから、PC を止める」ができない。**
> **PC を止めて、ラズパイで動かして、駄目なら戻す**という一発勝負になる。

だから**下ごしらえを全部済ませてから**、**短時間で**切り替える。

## やらない条件（どれか1つでも当てはまるなら、その日はやらない）

- **関門・見切りの材料を取る日**（9/28・9/29 午前）
- **人がキッチンに来る時間帯**（記録が落ちる）
- **本人が近くに居ない**（カメラの前でやり直しが要るかもしれない）
- **中継機がまだ届いていない**（回線が不安定なままでは、戻す意味が薄い）

## 下ごしらえ（2026-09-27 に済ませた）

| もの | 状態 |
|---|---|
| 橋渡しのコード一式 | `~/spirit_brain/bridge/`（PC と同じ版・md5 一致を確認） |
| python の道具 | `~/spirit_brain/venv`：numpy・PIL・onvif **あり**／cv2 は取り寄せ中 |
| 鍵 | `~/spirit_brain/spirit.env`（`SPIRIT_KEY=`・systemd が読める形） |
| 起動の仕掛け | `/etc/systemd/system/arigato-bridge.service`（**置いただけ・動かしていない**） |
| ffmpeg | あり |

**cv2 が無くても動く**（`shot_check.py` は cv2 が無ければ numpy で計算し、線も別に持っている）。
ただし**PC と同じ数字にするため、入れてから切り替える**ほうがよい。

## 切り替え（所要 5分・記録が止まるのは 1〜2分）

### 0. 前に必ず

- **進行役へ1行**（本番を止める作業。返事を待つ）
- 人感が静かなことを確かめる（`/spirit/health` の `camera` の経過秒）

### 1. PC 側を止める（**見張りも止める。ここを忘れると5分後に勝手に復活する**）

```powershell
Disable-ScheduledTask -TaskName ArigatoBridge
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -like '*tapo_bridge.py*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

### 2. ラズパイ側を動かす

```bash
sudo systemctl enable --now arigato-bridge
sleep 20; tail -5 ~/spirit_brain/bridge.log
```

### 3. 届いているかを確かめる（**2分以内に判断する**）

```bash
curl -s https://arigato-3ipecjbnha-an.a.run.app/spirit/health | python3 -m json.tool | head -20
```
- `camera` の経過秒が**増え続けていなければ成功**
- 橋渡しのログに「計測」の行が出ていれば送れている

### 4. だめなら戻す（**迷ったら戻す。粘らない**）

```bash
sudo systemctl disable --now arigato-bridge
```
```powershell
Enable-ScheduledTask -TaskName ArigatoBridge
Start-ScheduledTask  -TaskName ArigatoBridge
```

### 5. 済んだら

- **除外区間に、止めた時刻と戻した時刻を実測で書く**
- 進行役へ1行（成功／失敗・止まった時間）
- **1周が回ることを確かめる**（`python scripts/zone_check.py 1`）。
  ラズパイは PC より遅いので、**1周の時間が伸びていないか**を見る

## 戻したあとに残る宿題

- **見本の写真は PC で撮ったもの。**ラズパイでも同じ画角に止まるかは**確かめていない**
  （向きの補正 `aim_fix.json` は PC 側のファイル。**ラズパイにも同じものを置く必要がある**）
- PC 側の橋渡しは**消さずに残す**（戻せる状態を保つ）

# 追記（2026-09-30 夜）：中継器を入れて、回線が別物になった

**本人が中継器（TP-Link・AC1200）を中間地点（ルーターとラズパイの約10m地点）に置いた。**
電波の名前は元と同じ（`TP-Link_C452`）。**ラズパイはその 5GHz 側（`60:15:6f:6f:91:eb`）につながる。**

**9/19 に「映像が壊れて0枚」だった原因は、この回線の質だったと数字で説明がつく。**

  **再起動しても、弱いほうへ戻らない。**それまで両方とも 0 で、起動のたびにどちらに
  つながるか分からなかった（実際 9/30 に `spirit-net`・−75dBm につながっていた）
- ラズパイのアドレスは **192.168.0.102**（元どおり）。大学の有線（`eth0`・133.27.17.28）も残してある
