# 語りを聞く（設計・2026-09-24）

主張#6（関係が人ごとに積もる）を確かめる3つの方法のうちの③。
①時間差と②撤去期の落差は**顔が見分けられることに頼る**が、**③はそれに一切頼らない**。
2026-09-23 の実測で「来た人のうち名前が付くのは4回に1回・洗い物の姿勢ではとくに付かない」と分かったので、
**③の重みは上がった。**①②が薄くても、③だけは厚く取れる。

## いつ聞くか

**撤去期の終わりごろ（12/15 前後）に1回。**

- **観察の途中では聞かない。**聞いた時点から本人のふるまいが変わる（観察者効果）。12/6 までは何も聞かない
- **撤去のあとに聞く。**そうすれば「**あった**」と「**無くなった**」の両方を経験したあとになり、
  研究スケジュールの②（撤去期の落差）を、数字と語りの両方から見られる
- 1人30分以内。まとめて1日で終える必要はない

## 誰に聞くか

- **キッチンをよく使う人**（来訪の記録で上位の数人）。全員でなくてよい
- **呼び名が付いている人を優先**（装置が名前で呼んでいた人と、呼んでいなかった人の両方が居ると、対比になる）
- **装置に気づいていなかった人が1人でも居れば、その人にも聞く**（#5 の前提が崩れていないかの確認）

## 何を聞くか

**順番が大事。先に「気づいたか」を聞き、こちらから仕組みを説明しない。**説明したあとの答えは、説明への感想になる。

1. **キッチンを使うとき、あのキャラクターのことを意識しましたか。**（自由に話してもらう）
2. **どんなときに気づきましたか。**（何が目に入ったか・声だったか・顔だったか）
3. **自分に対する態度と、ほかの人に対する態度が違うと感じたことはありますか。** ← **#6 の核心**
   - あれば：どんなときに、どう違ったか
   - なければ：そのまま記録する（**否定の証言も証拠**）
4. **それで、何か変わりましたか。**（片づけるようになった／気にするようになった／何も変わらない）
5. **12月に顔が消えたことに気づきましたか。気づいたとき、どう思いましたか。** ← **②の語りの側**
6. （最後に）**いやだったこと、気持ち悪かったことはありますか。**（倫理の確認でもある）

### 聞かないこと
- 「役に立ちましたか」「よかったですか」（肯定を誘う）
- 「なつき度が上がっていたのを知っていましたか」（仕組みの説明になる）
- 片づけた回数の確認（数えられている感じを与える）

## 聞き方の決まり

- **こちらから仕組みを説明するのは、6問が終わったあと。**聞きたければ説明する
- **誘導しない。**「〜と感じませんでしたか」ではなく「どう感じましたか」
- **黙っている時間を埋めない。**
- **否定・矛盾する話ほど、そのまま書き留める。**装置の設計と食い違う証言が、いちばん値打ちがある
- 記述は岸政彦の方法に倣う（語りをまとめず、語られた順に置く）

## 記録の仕方

- **その場でメモ。録音は本人の同意があるときだけ**（掲示は「音は残さない」なので、インタビューは掲示の範囲外＝別に同意を取る）
- 文字に起こしたら、**本人に見せて「これでよいか」を確認する**
- 論文に載せるときは仮名

## 同意の取り方（本人が決めること・9/30 期限）

- 声をかける時期（撤油期の終わりごろ）と、断ってよいことを最初に言う
- 記録の残し方（メモか録音か）と、見せて確認することを先に伝える
- **キッチンの掲示とは別の同意**である（掲示は装置の記録について。インタビューは別）

## 予想される弱点（先に書いておく）

- **人数が少ない。**登録は12人、よく来るのは4〜5人。**事例研究として記述する**（一般化しない）
- **本人（研究者）が聞くので、気を遣った答えが出る。**→ 3番の「違うと感じたか」に「いいえ」が出たらそのまま書く。**いいえが出ることが、この問いが機能している証拠**
- 装置が見分けられなかった回が多いので、**その人が実際に受けた扱いは一定でなかった可能性**がある。
  → 3番で「ときどき違った」という答えが出たら、**記録と突き合わせる**（その日、装置がその人を見分けられていたか）。**これは①②では見えない照合になる**
