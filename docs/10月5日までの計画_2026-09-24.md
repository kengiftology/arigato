### **できていない・曖昧なところ（ここが研究の弱点）**

**① ベースラインが無い。これが一番痛い。**
研究スケジュールは「〜9月中旬＝試運転期＝実質のベースライン」と書いているが、実際にはその期間は
**「装置が無かった」のではなく「装置を作っていた」**期間で、毎日設定が変わっている。
比べられる「装置なしの共有空間」のデータは**事実上ゼロ**。
→ 主張#5（表情があると手が出る）の対照は、**撤去期（12/7〜12/20）の2週間しかない**。
→ しかも「10月以降は設定を変えない」と決めているので、途中で顔を消す週は作れない。
→ **撤去期に全部賭けることになる。だから撤去期の設計を、いま確定させておかないといけない。**

**② 主張#6（人ごとの関係）の検証方法が、3つのうち1つも動いていない。**
- ①時間差（なつき度が上がった後に世話が増えたか）→ 記録は取れているが**分析する道具が無い**
- ②撤去期の落差 → 12月。設計が未確定（①と同じ）
- ③語り（インタビュー）→ **相手も質問も時期も同意の取り方も未定**
→ #6 は新規性の核（竹のライン）。**証拠の取り方が決まっていないまま観察に入るのが最大の危険。**

**③ 誰か分かるのが 4回に1回（9/23：53回来て13回）。**
別人と間違えるのは 0 で合格ラインは満たしているが、「分からない」が 75%。
#6 は人ごとの系列を見る主張なので、**分からない回が多いほど人ごとのデータがスカスカになる**。
カメラは動かさないと決めたので、ここは**上げられるところまで上げて、どこかで見切る**しかない。

**④ 立ち寄り率・滞在時間（主張#25）が測れているか確かめていない。**
「来た人」は記録されるが、「通り過ぎた人」との区別があるか未確認。#25 を論文で使うなら凍結前に要る。

**⑤ 位置づけ（事例30件→マトリクス）が未着手。**
松川マニュアルで**最重要**とされる章。事例DBは21件あるが、**評価基準も採点もマトリクスも無い**。
→ この状態では「この山は未踏だ」と旗を立てられない。**考察の質は位置づけの精度で決まる。**
→ 開発ではないので凍結と無関係。**空いたマックをここに充てるのが、研究の強度に一番効く。**

**⑥ いま倫理の穴が開いている。**
対話が 9/23 22:07 から本番で動いているのに、紙の掲示（v4）がまだ貼られていない。**朝いちばんで塞ぐ。**

**⑦ 10週間ぶんの数字が確実に取れる保証がない。**
記録の口は最新1000件（いまは7時間ぶん）。`before=` で遡れるが、
自動実行は GitHub の間引きで中央値3時間10分遅れる（実測・9/23）。
止まったら気づく仕組みも、PC が死ぬと働かない（本人のコンソール操作待ち）。
