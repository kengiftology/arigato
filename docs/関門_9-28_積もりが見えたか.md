# 関門：9/28 夜「積もりが見えたか」（2026-09-24・E が用意／判断は進行役）

**なぜ置くか**：区画を増やすこと（症状）より、関係が積もること（病）が先。
9/28 に積もりが見えていなければ、9/29・9/30 は広げず、いまあるものを固める。

---

## 見るもの（4つ。①と②が通れば合格）

### ① 人ごとに違う区画に触れたか ★これが本丸
**通る条件：本番の記録で、2人以上について、それぞれ別の区画に触れた挨拶が1回以上ある。**

- 進行役の案は「ある人の挨拶がその人のよく整えた区画に触れた回が1回以上」。
  **1人だけだと足りない。**同じ挨拶が全員に出ていても条件を満たしてしまい、
  それは「積もり」ではなく「新しい定型文」だから。
- **人ごとに違う**ことが #6 の中身なので、**2人・別々の区画**を条件にする。

### ② 間違った相手に言っていないか ★落ちたら即やめる
**通る条件：別人の履歴に触れた挨拶が 0 回。**

- 9/23 の実測で、誰か分かるのは **4回に1回**（53回来て13回）。
  分からない人に「このあいだ、ここ、きれいになってたね」と言えば、**他人の手柄を別人に返す**ことになる。
  #12（誰が何をしたかを第三者に伝えない）にも触れる。
- **1回でも出たら、佇まいに出すのを止める**（履歴を貯めるところまでで固める）。
  誰か分かる率が上がるまで、出さない。

### ③ 履歴が実際に貯まっているか（前提の確認）
**通る条件：`cares_by_zone` が、2人以上・2区画以上に値を持っている。**

- 1人に偏っていたり、1区画しか動いていなければ、①が出ても偶然。
- ここが空なら、9/29 に何を出しても中身が無い。

### ④ 1周の実測（増やしてよいかの判断材料）
**数字を見るだけ。合否には使わない。**

- 1周（全区画を1回ずつ見る）にかかった時間
- 各区画の「前の写真」の古さ（中央値と最大）
- その日の首振り回数（**79回/日 を超えていないか**。超えたら前後比較が壊れる）

## 判定できないときの扱い（2026-09-25・A の報告を受けて先に決める）

A の `/spirit/history`（7日）で見えた現状：**人 6・区画 1・人×区画の組 6。**

**世話 64件の内訳（A の訂正・9/25）**：
| | 件数 | 人が付いた |
|---|---|---|
| 見回りが見つけた世話（人の欄あり） | 18 | **7件（39%）** ←**読むならこの数字** |
| C3 が知らせた世話（古い形・人の欄なし） | 46 | 0件（**測りようがない**） |

**`no_person 57/64＝89%` は読んではいけない。**46件は「分からなかった」のではなく**欄が無かった**もの。
C3 の世話に人の欄が付いたのは **9/24 19:01 から**で、それ以前は原理的に0%にしかならない。
**9/24 19:01 以降の C3 の世話はまだ0件**（最後の世話が 9/23 18:43・人が来ていない）。
**「何件に人が付くか」は 9/26 から初めて数えられる。**

| 起きうること | 扱い |
|---|---|
| 9/28 時点で **区画がまだ1つ** | **判定不能＝落ちたときと同じ扱い**（広げず、履歴を貯め続ける）。<br>区画が1つなら①「別の区画に触れた」も測れないので、**基準を下げると関門が形だけになる** |
| 人つきの世話が **2人ぶん出ていない** | 同上。数字を緩めない |
| `updated` が当日でない | **その日の分は入っていない。**数字を読む前に必ず見る |

**但し書き：分母が細い理由は、装置ではなく人の側にある（9/25・進行役）。**
- **9/23 22:07〜9/25 19:39:34 は対話の除外区間**（橋渡しが答えを取りこぼしていた）
- **シンクは 9/24 20:14 から「物あり」のまま動いていない＝2日間、誰も片づけていない**

→ 点検や関門で「判定不能」と出たときに、**装置の不備と読み違えないこと。**
世話が起きていなければ、履歴は貯まりようがない。
