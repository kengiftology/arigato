# 名前で呼ぶ／服で聞く：設計と見積もり（2026-09-22・研究トークC）

本人の依頼（9/22 21:3x）：①覚えた呼び名で呼んでほしい ②何人か居るとき、誰に聞いているか分かるよう服装などで呼びかけたい。
**まだ作らない。本人がこの文面を見て決めてから。**

---

## ① 名前で呼ぶ　── 見積もり 0.5日

### いまの作り
- 知っている人への迎えの一言（`for_p0X`）は、**人が居ない間にAIが文を作り**（`_prepare_greetings` → `_greet_line`）、
  **ラズパイの声係が VOICEVOX で音にして置いておく**（1本30秒かかるが、誰も居ない間なので困らない）。
- 1人につき4本まで持ち、見回りのたびに1本ずつ入れ替わる。

### 変えるところ
1. `_greet_line` に呼び名を渡す。指示文に1行足す：
   「相手の呼び名は『◯◯』。文の中で1回だけ、自然に呼ぶ（呼ばなくてもよい文もあってよい）。ひらがなで書く」
   - **ひらがなで書かせる**のは、VOICEVOX が漢字の名前を読み違えるのを避けるため（「桑原」→「くわはら」）
2. **呼び名を覚えた瞬間に、その人の4本を作り直す**（古い4本は名前が入っていないので）
3. 呼び名の無い人・番号が割れた人は、いままでどおり（呼ばない）

### 本人に決めてほしいこと
- **呼び方**：呼び捨て（「くわはら、おかえり」）／「さん」付け（「くわはらさん」）／「ちゃん」付け／AIにまかせる
  - キャラは子どものひとりごと調。「さん」は少し店員っぽくなる。**おすすめは呼び捨て**（親しさの段階が上がるほど自然）

### 気をつけること
- **顔を別の人と取り違えると、別の人の名前を呼んでしまう。** 9/17 以降、別人違いは0のまま（研究トークAの採点）。
- 声を作るのはラズパイの声係なので、声係が止まっていると新しい一言が出ない（そのときは名前の入っていない古い一言が鳴る）。

## ② 服で聞く　── 見積もり 1〜1.5日（うち半分は、2人そろう場面を待つ時間）

### 流れ
1. 迎えの場面で、呼び名の無い人に聞く番になる（いまと同じ）
2. **同じ写真に2人以上の顔が写っているときだけ**、次へ。1人のときはいままでどおり「なんて、よんだらいい？」
3. その写真から、**聞く相手の顔の下（体のあたり）を切り出して** Claude に見せ、
   「この人の服の色と特徴を、ひらがな10字以内で1つ」と聞く（例：「あかい ふくの」「めがねの」）
4. 問いかけをその場で声にする：「**あかい ふくの ひと、なんて よんだらいい？**」（クラウドの VOICEVOX・約2秒）
5. あとは今と同じ（聞き取る → 聞き返す → 覚える）

### 見てほしい点への答え
- **顔の枠は受け取れる。** 顔の検出（`face.detect_faces`）はもう顔の中心と幅を出している。
  いまは照合の結果に載せていないだけなので、`_identify` の返しに「中心・幅」を足す（数行）。
  ※研究トークAの持ち場（照合）の返しに項目を足すことになるので、書く前にAと調整する。
- **遅れ**：服を見るClaude 約1.5〜2.5秒 ＋ 問いかけの声 約2秒 ＝ **問いかけが約4秒遅れる**。
  聞くのは「30秒以上居る人」だけなので、4秒で去る心配は小さい。2人のときだけなので、1人のときは遅れない。
- **記録**：服の描写は記録に残す（文字を残す決定に合わせる）。写真そのものは今と同じ扱い。

### 気をつけること
- 「聞く相手」は写真の中で一番大きく写っている顔（＝カメラにいちばん近い人）。その人が向こうを向いていると、
  服の描写が本人に伝わらないことがある。
- 服の色はカメラの色味でずれる（照明が黄色いと白が黄色に見える）。「めがねの」「ぼうしの」など、色以外の特徴も許す。
