## 7. `docs/外れた見立て.md`（17件）

間違いで引くための索引。**いま見えている形は4つ。**

1. **考え直して気づいたものが 0 件。**すべて「測った」「別の人が見に行った」「動かして壊れた」
2. **理屈や状況証拠で当てにいくと、ほぼ外れる**（9/24 は進行役が同じ形で3回）
3. **書いた時点では終わっていない**（訂正そのものが外れる／決まりが守られない）
4. **手で決めた数字は古くなる**（20時間50分の停止の原因。区画が増えると3倍になる）

**進行役自身の外れを必ず載せること。**自分の外れが載らない索引は「他人の間違い帳」になって、誰も見なくなる。
