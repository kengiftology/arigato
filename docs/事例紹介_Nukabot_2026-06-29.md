# 事例紹介：Nukabot（ぬかボット）

*— 「環境に声を与える」をすでにやった先行研究。本研究（arigato）の位置づけの最重要比較対象 —*

---

## ひとことで

**ぬか床が、しゃべる。** センサーでぬか床の発酵状態を読み取り、ぬか床が一人称の声で「そろそろかき混ぜて」と人に世話を頼んだり、「調子はどう？」と聞けば答えたりするロボット。早稲田大学・ドミニク チェン研究室を中心とした混成チーム（デザイナー・エンジニア・発酵研究者）のプロジェクト。

- 公式：https://ephemere.io/nukabot

## 何をするものか

| 要素 | 内容 |
|---|---|
| 見た目 | 伝統的な木のぬか床容器（そこにセンサーとスピーカーが埋まっている） |
| 感知 | 内蔵センサーが発酵状態（微生物の活動）を多角的に読む |
| 振る舞い | 状態を**ことば**にして話す。かき混ぜ時期の**催促**、音声での質問応答。第4世代はGPT搭載で自然な会話 |
| しないこと | **かき混ぜの自動化はしない。** 手を動かすのはあくまで人 |

## 実績（知らない人への信頼材料）

- 国際会議 **ACM CHI 2021** で論文発表、**SIGGRAPH 2024** Emerging Technologies にも展示
- 日本科学未来館・**21_21 DESIGN SIGHT**・ミラノトリエンナーレなどで展示
- 情報処理学会論文誌（2023）掲載

## 研究として大事なポイント（4つ）

1. **自動化ではなく「関係」を作る。** 目的はぬか漬けの効率化ではなく、人が微生物を「パートナーとして認める心の働き」を育てること。ロボットは微生物の**通訳**であって、監視員でも代行者でもない。
2. **催促が嫌がられない。** 「かき混ぜて」は要求なのに、命令ではなく生き物の声として受け取られる（人を責める主体がいない）。
3. **ケアを3つの要素で分析した。** 6人の参加者が10日間ぬかボットと暮らすフィールド調査を行い、その経験を **maintenance（維持）・affection（愛情）・obligation（義務）** の3要素で分析した。
4. **「卒業」という成功条件。** ユーザーはやがてぬかボットなしでも身体感覚でぬか床と付き合えるようになる＝**道具が要らなくなったら成功**、という設計思想。

## 本研究（arigato）との関係

### 似ているところ（借りられる概念）

| Nukabotの概念 | arigatoへの翻訳 |
|---|---|
| 環境（微生物）に声を与える | 場所に声を与える（場所が一人称で話す） |
| センサー＝監視でなく**通訳** | カメラ＝監視でなく**場所の通訳**（見られてる感への回答） |
| 自動化しない（かき混ぜるのは人） | 掃除ロボットにしない（片づけるのは人。アプリはありがとうを"作らず"、埋もれたものを"通す"だけ） |
| 生き物の声の催促は圧にならない | 場所の独り言なら、人からの注意が嫌な人にも届くかもしれない |
| 維持・愛情・義務のケア3要素 | 本研究の理論の分岐（交換／愛着／気にかけ合い／義務=規範）を分析する枠組みとして輸入できる |
| 卒業＝道具なしでケアが残れば成功 | **アプリなしでも場所を気にかける習慣が残れば成功**（長期の成功条件） |
| 6人×10日の設置＋インタビュー | 評価方法の型（実生活に置いて、ログと語りで関係の変化を見る） |

### 決定的な違い（＝本研究の新しさ）

|  | Nukabot | arigato（本研究） |
|---|---|---|
| 場 | 家庭内 | **共有空間**（ゼミ室・畑） |
| 関係 | 1対1（1世帯と1つのぬか床） | **多対1対多**（多くの人と1つの場所） |
| ケアの返礼 | おいしい漬物（モノ） | **ありがとう（承認）** |
| 人と人の関係 | 存在しない | **承認が場所を経由して人々の間を流通する** |

> **「環境に声を与える」まではNukabotがやった。**
> **「声を持った環境を、複数人の感謝が流れるハブにする」のは、まだ誰もやっていない。ここが本研究の山。**
