ここでは「やった事」と「そこから見えてきた問い」をセットで並べる。

## 2. やった「理由」

あとから振り返って言語化したもの。

- 汚かったから
- **自分も使う場所**だから
- 綺麗だと**嬉しい**から

→ 誰かに頼まれたわけでも、見返りがあるわけでもない。
**利己的な動機**（自分が気持ちいい）で始まっている。

## 3. できていなかった「理由」

ずっと「やった方がいい」とは気づいていた。でも動けなかった。

- **まとまった時間がなかったから**

→ 動かなかったのは、やる気の問題でも能力の問題でもない。
ボトルネックは**時間ときっかけ**だった。

---

## 4. そこから浮かび上がってきたもの

### 発見① 維持は一人で完結した。改変は他者を巻き込んだ

- 維持（片付け・清掃・断捨離）は、**自分一人で完結**した
- 改変（調理棚の増築）は、**小栗・松川・シマさんのFBが自然に入ってきた**

同じ「手入れ」なのに、改変のときだけ他者の手と判断が入った。
**なぜ？**

### 発見② 改変には「判断の余地＝隙間」があるから、人が入れた

- 維持＝原状回復。正解は一つ（元に戻す）。他人が口を出す余地がない
- 改変＝設計。正解は複数（こう置く／こう作る）。**だから他人の判断が入れる**

「自分もやってみたい／口を出したい」が起きるのは、
**そこに判断の余地（隙間）があるとき**だった。

### 発見③ 駆動していたのは「ありがとう」ではなく「設計の楽しさ」

- 棚を増築しているとき、楽しかった
- 「これかっこいい」「これだと綺麗に収まる」「これだと使いやすい」
- これは普通に**設計・施工と同じ**快感

→ 人を動かしていたのは報酬でも感謝でもない。
**手を動かして空間を良くすること自体の気持ちよさ**だった。

### 発見④ 利己で始めたのに、結果は次の人の役に立っている

- 動機は利己的（自分が気持ちいいから）
- でも、整った棚・片付いたキッチンは、**次に使う人**の役に立つ
- **利己的にふるまったら、気づいたら利他的になっていた**

### 発見⑤ 環境は「ありがとう」を返してこない

- 片付けても、棚を作っても、**環境は何も言わない**
- 綺麗になった事実があるだけ
- 「やってよかった」を環境は教えてくれない

→ では、その手入れが役に立ったことは、誰が証明するのか？
（→ ヒトからの「ありがとう」。ここは別資料で扱う）

## 5. 一枚にまとめると

```
   利己的な動機（汚い・自分も使う・嬉しい）
            │
            ▼
   手を動かす ──┬── 維持（片付け）→ 一人で完結
               └── 改変（棚の増築）→ 他者のFBが入る
                              │
                  「判断の余地＝隙間」があるから
                              │
                              ▼
              他者が巻き込まれ、手と判断が乗る
                              │
                              ▼
         結果として、次に使う人の役に立つ（利己→利他）

   ※ 駆動力 ＝ 設計の楽しさ（ありがとうではない）
   ※ 障壁  ＝ 時間ときっかけ（やる気ではない）
   ※ 環境は返礼しない（役立った証明はヒトの「ありがとう」が担う）
```

---

## 6. ここから立つ研究の問い

実際にやってみて、一番強く浮かんだのはこれ：

> **維持は一人でもできた。**
> **では、判断の余地（隙間）のある「改変」は、他者を巻き込んで連鎖していくのか？**

維持と改変を分けず「手入れ」として束ねたとき、
その手入れが**次の人の手を呼び、続いていくか**を観察したい。

（駆動力・ありがとう・交換ではない、という理論的な整理は別資料に分ける）
