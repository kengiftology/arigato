# いちばん見たい場面で、いちばん顔が撮れない（2026-09-24）

カメラ1台で共有空間の世話を捉えようとすると、**世話をしている姿勢そのものが、
その人を見分けられなくする**。

この文書は初め、これを「置き方から出てくる限界」とだけ書いていた。
だが調べていくと、**半分は装置の作りの側の話だった**（後半「どこまで解けるか」）。
置き方の限界と、作りで解ける分は分けて書く。分けないと、
直せるものを「仕方ない」と書いてしまう。

## 何が起きているか

キッチンの地霊は、入り口を向いて待っている。人は数秒で通り過ぎるので、
物音がしてから振り向いたのでは顔に間に合わないためである。
シンクの前に立った人は、カメラから見て**横を向き、下を向く**。

9/16〜9/24 の記録（16,642件）で、人を見たのに名前がつかなかった理由を数えると：

| 弾いた理由 | コマ数 |
|---|---:|
| **下を向いている**（looking_down） | **64** |
| 顔が小さすぎて照合できない（too_small_to_match） | 25 |
| 1コマしか撮れていない（one_frame） | 19 |
| 家具と見分けがつかない（furniture） | 9 |
| 正面でない（not_front） | 6 |
| 決めかねた（hold） | 2 |
| 見切れている（cut_off） | 2 |

**最多は「下を向いている」である。シンクで洗い物をしている人の姿勢そのものだ。**

## なぜ構造的か

この装置が記録したいのは「誰が世話をしたか」である。
ところが世話の最中は、

- 顔が下を向く（洗う・拭く・しまう）
- 体がシンクに向くので、入り口を向いたカメラからは横顔か後頭部になる
- 手元に集中しているので、カメラのほうを見る理由がない

つまり、**記録したい行為をしている時間が、そのまま顔を撮れない時間**になる。
入り口で「こんにちは」とすれ違う数秒のほうが、よほど顔が撮れる。

同じ期間の「誰か分かった率」は 25.9%（9/23 は 15/58）。
顔の大きさは中央値 98px で、照合に要る 100px をわずかに下回る（9/23・484回の実測）。
カメラを 30〜40cm 近づければ中央値は 150px 前後になる見込みだが、
**近づけると画角が狭まり、入り口とシンクの両方は写せない。**
どちらを撮るかという選択であって、両立はしない。

## 記録にどう効いているか

世話の手柄は「その滞在で名前がついた人」に行く。
名前がつかなかった人は、**居たことは残るが、手柄の候補にならない**。

9/16〜9/24 に手柄が確定した滞在 40件のうち、
「手柄の人を最後に見てから見回りまでに、名前のつかない顔が写った」のは 29件。
その29件の切り抜き505枚を、登録済みの人の重心と突き合わせた（研究トークA）。
**滞在の件数**でまとめると（手柄は滞在ごとに1回決まるので、枚数ではなく件数で数える）：

| | 件数 |
|---|---:|
| 測れた滞在 | 27 |
| うち **登録済みの誰とも合わない顔があった** | **21** |
| うち **名前なしの大半がそれだった**（手柄が未登録の人のものだった疑いが濃い） | **12** |
| 同じ人の撮り損ねだけだった | 2 |
| 判定できる切り抜きが無かった | 3 |
| 測れなかった（手柄の人の重心が作れない・09/20 00:47 p04、09/20 17:20 p06） | 2 |

**取り違えの正体は「別の登録者に手柄が付け替わる」ことではなかった**（別の登録者は切り抜きの3%）。
**「未登録の人が同席していた」**ことである。未登録の人が片づけても、その人は手柄の候補になれないので、
手柄はその場に居た登録済みの人に行く。

したがって取り違えの余地は **多く見積もって 12/27 = 44%**。
ただしこれは上限である。「登録済みの誰とも合わない」には
(a) 本当に未登録の人 (b) 手柄の人の極端な角度 (c) 物や誤検出 が混ざる。
**確かめが取れているのは 9/23 18:29 の1件だけ**（未登録のBさんとして顔を見て確認）。
→ **12件の顔を並べた画像を本人が見れば確定する。2026-09-24 時点で返事待ち。**

### 上限が上限である理由（この装置でいちばん大事な方法上の注意）

「登録済みの誰とも合わない」は、**同じ人でも姿勢が違えば出る**。
9/24 に窓ごとの顔をまとめ直して比べたところ（研究トークA）：

- 09/20 09:42 の「誰とも合わない顔」の群は、**手柄の p02 本人と 0.50**（同じ人の線は 0.46 以上）
- 09/19 09:53 の群は p02 と 0.42 で、線をわずかに下回る（＝「合わない」と出る）
- ところが **09/19 の群と 09/20 の群どうしは 0.68**（＝同じ人だと強く出る）

つまり**同じ人でも、正面の登録写真と比べると 0.42 まで落ち、
同じうつむきどうしで比べると 0.68 に上がる**。
比較の基準が「正面の重心」なので、**うつむいた姿勢は体系的に『知らない人』の側に寄る。**

この3つの窓（09/19 09:53・09/20 09:42・09/23 13:00）に出てくる顔は、
いずれも p02 のうつむきと読むのが自然で、**12件のうち少なくとも3件は「未登録の人」ではない。**

はっきり別人と言えるのは 09/23 18:29（手柄=p01,p13・群3つ・手柄の人と 0.03）だけで、
これが未登録のBさんである。

**この性質は、この装置の数字を読むときに常に効く。**
「知らない人が居た」と出たものの一部は、**知っている人が下を向いていただけ**である。
未登録の人の数は、放っておけば多めに出る。

（2026-09-24 の記録：この数字は 0% → 65% → 5% → 44%（上限）と動いた。
0% は「別の人」を名前つきの人だけで数えた誤り。65% は「名前がつかない」を「別人が居る」と読んだ誤り。
5% は「別の登録者に付け替わる」話に限った数字で、未登録の人の同席を数えていなかった。
**記録から人の出入りを読むのは、記録の列を数えるだけでは足りず、顔の切り抜きまで戻らないと決まらない。**
この経緯自体が、記録だけで人を追うことの難しさを示している。）

## どこまで解けるか：うつむきを、照合にだけ使う

この限界は全部が置き方の話ではなかった。**装置の側が、うつむいた顔を最初から見ようとしていなかった**。
起き具合1.70を超える顔は、照合にも使われずその場で捨てられていた（`spirit.py` の `if not up: return None`）。
「下を向いている」が弾いた理由の最多だったのは、姿勢のせいであると同時に、この作りのせいでもある。

そこで、うつむいた顔を**照合にだけ**使うようにして測った（研究トークA・9/24）。守る条件は3つ。

1. **その1枚だけで決める**（数コマの平均に混ぜない）
2. **そこから新しい人は作らない**
3. **覚えには入れない**

1 が要になる。うつむきのコマを平均に混ぜると、**同じ束ねの中の正面のコマの点数まで下がり**、
決まらなかった顔が後で新しい人として登録されて、IDが割れた（実測：7個→10個）。
混ぜずに1枚で決めると、割れは起きない。

9/12〜9/15 の本人分類 2,306枚を、何も覚えていない状態から本番のコードで再生した結果。
表の C・B・D・K は、切り抜きを手で仕分けたときの分類の記号で、この期間に最も多く写った4人を指す。
**装置が付ける ID（p01…）とは別物で、採点のための正解の側である**（実名は扱わない）。
同じ人が複数の ID に割れることがあるので、人の単位で数えるには正解の側の記号が要る。
表の「IDの数 7個」と「4人」が食い違って見えるのは、そのためである。

| | 名前が付いた顔 | 別人に付いた | IDの数 | C | B | D | K |
|---|---:|---:|---:|---:|---:|---:|---:|
| いまの装置 | 860 | 0 | 7 | 38.2% | 21.0% | 69.1% | 19.7% |
| うつむきを平均に混ぜる | 881 | 0 | 10 | 29.2% | 35.7% | 70.2% | 26.0% |
| **うつむきを1枚で照合（採用）** | **1078** | **0** | **7** | **48.2%** | **37.6%** | **71.8%** | **31.2%** |

名前が付く顔が **+25%**、取り違えは 0 のまま、IDも増えない。**4人全員が上がる。**
別の期間（9/16〜9/17・325枚）でも 29→40枚（+38%）・別人0・ID数そのままで同じ向きだった。

## 解き方の限界：覚えに入れると、人を取り違える

同じ枠組みで「うつむいた顔を覚えにも入れる」を試すと、名前が付く顔は 1201枚（+40%）まで伸びるが、
**別人に名前が付く顔が1枚出た**。内訳を見ると `0915_154051_102px_dn_unknown.jpg`＝
**C のうつむいた顔が B の ID に付いた**もので、重心の当てにならない古いIDの巻き添えではなく、本物である。

> **うつむいた顔は、照合には使えるが、覚えに入れると人を取り違える。**
> 覚えに入れると重心が「うつむき一般」に寄り、人の違いより姿勢の共通性が勝つため。
> 実測：照合にだけ使うと別人0／覚えにも入れると 1201枚中1枚（C のうつむきが B の ID に付いた）。

人ごとの系列（主張#6）では、取りこぼしは後から埋められるが、取り違えは系列そのものを汚す。
そこで **+123枚は取らず、照合にだけ使う形を採った**。測ったうえで採らなかった選択として記録しておく。

## 書くときの言い方

弱点の告白としてではなく、**置き方が決める限界**として書く。

> カメラを1台だけ置くとき、その向きは「誰が来たか」と「何をしたか」の
> どちらを取るかの選択になる。入り口を向ければ人は分かるが手元は見えず、
> 手元を向ければ作業は見えるが顔は下を向いていて分からない。
> 本研究の装置は前者を選び、その結果として、
> 世話をしている最中の人をもっとも見分けにくいという性質を持つ。

この性質は、**世話の総量を数えることはできても、世話を人に割り当てることには弱い**という形で
結果に効く。人ごとの系列（主張#6）を扱うときは、この限界を前提に読む必要がある。

ただし**「仕方ない」で終わらせない**。うつむいた顔を照合にだけ使う形にすると、
名前の付く顔は 25% 増え、取り違えは増えなかった。**置き方が決める分と、作りで解ける分は違う。**
そして解ける分にも限界があり、**覚えに入れた途端に人を取り違える**。
このように、どこまでが置き方の宿命で、どこからが設計の選択かを分けて示せることが、
実機を作って測ったことの値打ちだと考える。
