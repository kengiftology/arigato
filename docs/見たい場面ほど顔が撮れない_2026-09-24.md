# いちばん見たい場面で、いちばん顔が撮れない（2026-09-24）

カメラ1台で共有空間の世話を捉えようとすると、**世話をしている姿勢そのものが、
その人を見分けられなくする**。これは調整で詰める不具合ではなく、置き方から出てくる限界である。

## 何が起きているか

キッチンの地霊は、入り口を向いて待っている。人は数秒で通り過ぎるので、
物音がしてから振り向いたのでは顔に間に合わないためである。
シンクの前に立った人は、カメラから見て**横を向き、下を向く**。

9/16〜9/24 の記録（16,642件）で、人を見たのに名前がつかなかった理由を数えると：

| 弾いた理由 | コマ数 |
|---|---:|
| **下を向いている**（looking_down） | **64** |
| 顔が小さすぎて照合できない（too_small_to_match） | 25 |
| 1コマしか撮れていない（one_frame） | 19 |
| 家具と見分けがつかない（furniture） | 9 |
| 正面でない（not_front） | 6 |
| 決めかねた（hold） | 2 |
| 見切れている（cut_off） | 2 |

**最多は「下を向いている」である。シンクで洗い物をしている人の姿勢そのものだ。**

## なぜ構造的か

この装置が記録したいのは「誰が世話をしたか」である。
ところが世話の最中は、

- 顔が下を向く（洗う・拭く・しまう）
- 体がシンクに向くので、入り口を向いたカメラからは横顔か後頭部になる
- 手元に集中しているので、カメラのほうを見る理由がない

つまり、**記録したい行為をしている時間が、そのまま顔を撮れない時間**になる。
入り口で「こんにちは」とすれ違う数秒のほうが、よほど顔が撮れる。

同じ期間の「誰か分かった率」は 25.9%（9/23 は 15/58）。
顔の大きさは中央値 98px で、照合に要る 100px をわずかに下回る（9/23・484回の実測）。
カメラを 30〜40cm 近づければ中央値は 150px 前後になる見込みだが、
**近づけると画角が狭まり、入り口とシンクの両方は写せない。**
どちらを撮るかという選択であって、両立はしない。

## 記録にどう効いているか

世話の手柄は「その滞在で名前がついた人」に行く。
名前がつかなかった人は、**居たことは残るが、手柄の候補にならない**。

9/16〜9/24 に手柄が確定した滞在 40件のうち、
「手柄の人を最後に見てから見回りまでに、名前のつかない顔が写った」のは 29件。
その29件の切り抜き505枚を、登録済みの人の重心と突き合わせた（研究トークA）。
**滞在の件数**でまとめると（手柄は滞在ごとに1回決まるので、枚数ではなく件数で数える）：

| | 件数 |
|---|---:|
| 測れた滞在 | 27 |
| うち **登録済みの誰とも合わない顔があった** | **21** |
| うち **名前なしの大半がそれだった**（手柄が未登録の人のものだった疑いが濃い） | **12** |
| 同じ人の撮り損ねだけだった | 2 |
| 判定できる切り抜きが無かった | 3 |
| 測れなかった（手柄の人の重心が作れない・09/20 00:47 p04、09/20 17:20 p06） | 2 |

**取り違えの正体は「別の登録者に手柄が付け替わる」ことではなかった**（別の登録者は切り抜きの3%）。
**「未登録の人が同席していた」**ことである。未登録の人が片づけても、その人は手柄の候補になれないので、
手柄はその場に居た登録済みの人に行く。

したがって取り違えの余地は **多く見積もって 12/27 = 44%**。
ただしこれは上限である。「登録済みの誰とも合わない」には
(a) 本当に未登録の人 (b) 手柄の人の極端な角度 (c) 物や誤検出 が混ざる。
**確かめが取れているのは 9/23 18:29 の1件だけ**（未登録のBさんとして顔を見て確認）。
→ **12件の顔を並べた画像を本人が見れば確定する。2026-09-24 時点で返事待ち。**

（2026-09-24 の記録：この数字は 0% → 65% → 5% → 44%（上限）と動いた。
0% は「別の人」を名前つきの人だけで数えた誤り。65% は「名前がつかない」を「別人が居る」と読んだ誤り。
5% は「別の登録者に付け替わる」話に限った数字で、未登録の人の同席を数えていなかった。
**記録から人の出入りを読むのは、記録の列を数えるだけでは足りず、顔の切り抜きまで戻らないと決まらない。**
この経緯自体が、記録だけで人を追うことの難しさを示している。）

## 書くときの言い方

弱点の告白としてではなく、**置き方が決める限界**として書く。

> カメラを1台だけ置くとき、その向きは「誰が来たか」と「何をしたか」の
> どちらを取るかの選択になる。入り口を向ければ人は分かるが手元は見えず、
> 手元を向ければ作業は見えるが顔は下を向いていて分からない。
> 本研究の装置は前者を選び、その結果として、
> 世話をしている最中の人をもっとも見分けにくいという性質を持つ。

この性質は、**世話の総量を数えることはできても、世話を人に割り当てることには弱い**という形で
結果に効く。人ごとの系列（主張#6）を扱うときは、この限界を前提に読む必要がある。
