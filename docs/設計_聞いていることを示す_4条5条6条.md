# 設計：聞いていることを示す（憲法 4条・5条・6条）

『弱いロボット』から引いた8条のうち、**4（相手の拍に合わせる）・5（間を置く）・
6（ためらいを音にする）**の実装設計。2026-09-06。

この3つは共通して**「音を出すこと」ではなく「相手に注意を向けていること」の現れ**。
残りの5条は音そのものの作り方だが、この3つは**時間の使い方**の話になる。
「かわいらしさがない」の残りの正体は、おそらくここ。

---

## 前提：耳がない問題と、その解

C3（キャラ本体）にマイクは無い。**しかしTapoのRTSPには音声が乗っている。**
ラズパイは既にその映像を開きっぱなしにしているので、**同じ接続から音も取れる。**

```
Tapo（映像＋音声）
   ↓ RTSP
ラズパイ ─ 映像 → 動きの見張り（既存）
        └ 音声 → 話し声の拍を測る（新規）
   ↓
クラウド ─ 型と間を決める
   ↓
C3 ─ 鳴らす
```

**音声認識は使わない。** 何を言ったかは要らない。**いくつの拍で、どれだけの長さか**
だけが要る。音量の山を数えるだけで足りる（映像の見張りと同じ考え方）。

---

## 第4条：相手の拍に合わせて返す

### 測るもの

| | 何のために |
|---|---|
| 拍の数 | 返す粒の数を決める |
| 全体の長さ | 返す長さを決める |
| 最後が上がったか下がったか | 問いかけか、独り言かの手がかり |

「こんにちは」（4拍・1.2秒・下がる）→ 4粒・1.0秒くらいで返す。
**同じ数で返す必要はない。7〜8割にすると、控えめに聞こえる**（第7条と同じ理屈）。

### 実装

ラズパイ側に、映像と同じ形で音声を流しっぱなしにする出力を足す。

```
ffmpeg -i <RTSP> \
  -vf ... -f rawvideo pipe:1        # 既存の見張り
  -vn -ac 1 -ar 8000 -f s16le pipe:3   # 追加：話し声用
```

8kHzで足りる（拍を数えるだけ）。30msの窓で音量を測り、静かな時の値から
持ち上がった山を数える。**映像の見張りと同じ処理**なので、コードは流用できる。

拍を数えたら `/spirit/frame` の返事と同じ経路でクラウドへ渡す：
`POST /spirit/heard?beats=4&sec=1.2&rise=0`

### 注意

**キャラ自身の声を拾ってしまう。** 鳴らしている間と、その後1秒は数えない。

## 第5条：間を置く

### 決まり

| | 秒 |
|---|---|
| 最短 | **0.8**（0.3秒以内は「軽率」。憲法のやらないこと） |
| ふつう | 1.0〜1.6（毎回ばらす） |
| 迷ったとき | 2.0〜3.0（第6条と組む） |

### なぜ間が要るか

**すぐ返すと、聞いていたのではなく反射したように見える。** 間があると、
受け取って、考えて、返した——という順序が生まれる。
`_greet` の返事を即座に返すのをやめ、**「まだ準備中」を返す**形にする。

### 実装

クラウドの状態に `speak_at`（鳴らしてよい時刻）を持つ。

```
人を見つけた           → speak_at = いま + 0.8〜1.6秒（ばらす）
ためらう型を選んだとき → speak_at = いま + 2.0〜3.0秒
```

C3は `/spirit/voice.pcm` を取りに来るが、`speak_at` 前なら **204（中身なし）**を返す。
C3側の変更は要らない。**取りに来ても何も無い、が間になる。**

## 第6条：ためらいを、音にする

### 形

```
[迷い] えーと…なんだろうな…    低く・平ら・長め・粒の間隔も広い
[間]   0.9〜1.1秒              ここがいちばん効く
[答え] きいろー!               高く・短く・跳ねる
```

『弱いロボット』p.148 の療育記録そのまま。**あきらめそうになったころに答える。**

### いつ使うか

**毎回やるとくどい。** 次のときだけ：

| 場面 | 理由 |
|---|---|
| 初対面の人 | 「誰だっけ」と迷うのが自然（既存の「とぼける」と一致） |
| 久しぶりの人 | 思い出そうとしている |
| 何かが変わったと気づいたとき | 何が変わったか探している |

**それ以外は迷わず返す。** 迷いが特別なときにだけ出ると、迷いに意味が生まれる。

### 実装

`babble2.py` の `HESITATE` に型を持たせてある（迷い→間→答え）。
どの型を選ぶかをクラウド側で決め、PCMに組み立てて返す。

---

## ぎこちなさを残す（p.159）

**「む〜」からの反応はちょっとぎこちないくらいのほうが人気が高い。**

意図的に残すもの：

- **間の長さを毎回ばらす**（1.0秒固定にしない）
- **粒の選び方をばらす**（同じ音を返さない・プルンのゆらぎ p.45）
- **たまに反応しない**（10回に1回くらい黙る）
- **拍を数え間違えてもよい**（正確に合わせない。7〜8割で返す）

**正確さを上げると、かわいくなくなる。** ここは磨かない。

---

## 作る順番

| | 何をするか | どこ |
|---|---|---|
| 1 | 間を置く（第5条） | クラウドだけ。**いちばん軽く、いちばん効く** |
| 2 | ためらいの型（第6条） | 音は作成済み。選ぶ処理を足すだけ |
| 3 | 拍を測る（第4条） | ラズパイに音声の出力を足す。いちばん重い |

**1から順に。** 1と2はカメラの作業と競合しない。

---

## 憲法との対応

- 第4条 … 拍を数えて返す。音声認識は使わない
- 第5条 … 0.8秒未満では返さない。毎回ばらす
- 第6条 … 迷い→間→答え。特別なときだけ
- 第7条 … 返す長さを相手の7〜8割に（控えめ）
- やらないこと … 同じ音を返さない・即答しない
