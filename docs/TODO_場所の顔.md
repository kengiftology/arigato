## 4. 顔の実装（構想→コード）

- [ ] 表情の語彙を確定（場所が取りうる状態のリスト）
  - ふだん／気づいた／散らかってる／整えてもらった／ありがとう着信／眠い
- [ ] 目・口の部品システムをST7789用コードに（目10・口9・位置固定）
- [ ] 整い度(連続1軸)→表情の連続変化
- [ ] 割り込みイベント（気づいた=PIR即／ありがとう着信／眠い=無反応タイマー）
- [ ] 見過ごされ度→エスカレーション（人が通っても整わない→訴えを強める）
- [ ] ★ 瞳に映像を映す（実現性の検証：小さい瞳で読めるか→ズーム演出で救う）
- [ ] 表情の時間遷移を詰める（じわ変化／まばたきで挟む／滞留時間）
- [ ] 音（AtomS3）と顔の感情を揃える（気づいた時に音＋視線を同時に）

### 崩してはいけない設計原則（明文化して守る）
- [ ] 数値（整い度%）は人に見せない。内部だけ。人が受け取るのは表情のみ
- [ ] ★ 責めない・怒らない。強めるのは「見て・助けて」の必死さだけ（怒り=叱責Bの再現=研究の破綻）
- [ ] 汚くても表情を悪化させ続けない・眉で睨まない。狙う感情は「助けたい」で「怒られた」ではない
- [ ] 顔の輪郭は描かない（目と口だけ浮かせる＝物が頭になる）
