# 人ごとの地霊 ── 愛着が湧く設計の案（2026-09-23・進行役の叩き台）

本人の問い（9/23 朝）：「一通りできた。より愛着が湧く設計にするには？ 人ごとにエージェントを作り、キャラに人ごとの個性を出したい。場所の維持も継続して行える形で。」
主張台帳 **#6「人ごとの地霊は1キャラより愛着を強める」** の実験そのもの。凍結（10/4）まで 11 日。

## いまあるもの（人ごとに既に分かれているもの）
- なつき度と段階（知らない→見たことある→顔見知り→なついている→べったり）。会わなくても減らない
- 段階に応じた**その人向けの一言**（AI が作る・`_greet_line(persona, manner, name…)`）。9/23 から呼び名つき
- **喜び**（段階3以上で1回）。`c3_joy` に誰に喜んだかが残る
- 世話の記録（誰が・いつ・何を片づけたか）、呼び名

## いま共通のもの（＝個性が出ていない所）
- **声**：全員ずんだもん（VOICEVOX 話者 3）
- **話し方の種**：段階の指示文だけ。人ごとの「性格」は無い
- **思い出**：一言は「その人が前に片づけたか」しか見ていない。「何を」「いつ」は言わない
- **見た目**：C3 の顔・絵は1種類（フラッシュ 93%・大きな絵は増やせない）
- **身体**：C3 は1台。皆が同じ身体を見る（9/22 決定④：温かさは第三者に見せる）

## 考え方（提案）
**身体（C3）と「場所の気持ち」は1つのまま。人ごとに分かれるのは「その人に向く顔＝声・口ぐせ・思い出」。**
- 場所の維持のループ（見回り→シンクの様子→なつき度）は今のまま動かす。地霊が「場所の気持ち」を言う部分は共通
- 知っている人が来たとき（迎え・喜び・呼び名）だけ、**その人の地霊**として話す
- 「人ごとのエージェント」は、**人ごとの状態（声・性格の種・思い出・段階）を持った、同じ仕組みの別の口**として実装する（1人1プロセスは要らない）

## 部品（小さい順）

**10/4 までに入れる案**：1 → 2 → 3（合計 2〜2.5 日）。4 は余力。5 は凍結後（絵の制約が大きい）。6 は 3 と一緒に。

## 研究として測るもの（台帳#6）
- 人ごとの**来訪の間隔**・**片づけの回数**・**呼び名を答えた率**を、地霊の個性が入る前（9/19〜10/1）と後（10/2〜）で比べる
- 「同じ部屋の別の人が、他人の地霊の温かさを見た」場面（`c3_joy` の `person_now` と `boxes`）の回数
- 声を人ごとにした瞬間の反応（初回の一言に対する滞在の長さ・答えの有無）

## 決めてもらうこと
1. 10/4 までに入れる範囲（1〜3 か、1〜2 か）
2. 性格の種を「世話の仕方で自動」にするか「本人が人ごとに指定」にするか
3. 声の候補（子どもの声 4〜6 種）を本人が聞いて選ぶか、任せるか
