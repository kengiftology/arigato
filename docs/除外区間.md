# 除外区間（記録が取れていなかった時間）

数字を読むときに、ここに挙げた時間は**分母からも分子からも外す**。
外さないと「その時間に何も起きなかった」と読めてしまい、実際は「見ていなかった」だけになる。

**数字は「生」と「除外後」の両方を出す。**片方だけにすると、都合の悪い区間を消したように見える。

## この表の使いどころ（2026-09-25 に決めた）

- **過ぎた区間はこの表に書く。**`POST /spirit/period` は**呼んだ時刻**で境目を刻むので、
  過去の停止をいま呼ぶと、記録の上では「今日その停止が始まった」ことになる。
  論文の材料に嘘の時刻を混ぜないため、**過去はこの表、これから起きる停止は `/spirit/period`** と分ける
- `scripts/day_report.py` がこの表を読んで「除外後」を出す

## 書き方

| 列 | 中身 |
|---|---|
| 開始・終了 | **実測の時刻**（ログや記録から。見積もりで書かない） |
| 理由 | 何が止まっていたか |
| 誰が | 止めた人（試験なら誰の試験か） |
| どの数字に効くか | その区間で取れていない数 |
