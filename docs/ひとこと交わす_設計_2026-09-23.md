# ひとこと交わす（対話）の設計・2026-09-23

本人：「もう少し対話できるようにしたい」→「キッチンに行くたびに1回でよい」「しゃべりたい人はしゃべりたいので、うまく設計したい」。

## 決めた形

- **来訪ごとに1回**、キャラから話しかける（来訪＝いまの滞在の区切り。30分以内の出入りは同じ来訪）。
- **そのあとは相手しだい**。返事があれば続き、黙ればそこで終わる。**キャラからは追いかけない。**
- 上限は **1来訪6往復・3分**。
- 話しかけるのは、迎えの一言が鳴り終わってから（同じ口を取り合わないため）。呼び名を聞いている最中は話しかけない。

## 流れ

```
迎えの一言（名前入り・思い出入り）が鳴る
  ↓ 鳴り終わってから
「きょうは なに するの？」など1つ（その場で声にする）
  ↓ 十数秒きく（答え終わりで締める）
文字にする → 一言だけ返す（20字以内・子どものひとりごと調・質問で返さない）
  ↓ 相手がまた話す → また返す（6往復・3分まで）
  ↓ 黙る → 終わり
```

## 決まり

- 聞く文は6本から選び、**前回と同じものは選ばない**（`faces.last_q` に覚える）。
- 返しは Claude。**命令しない・お願いしない・評価しない・数や回数を言わない**（迎えの一言と同じ掟）。
  **質問で返さない**（相手が話したければ勝手に続く。こちらから引き出さない）。
- 聞き取った文字は、その人の `faces.said` に残す（しゃべり方を写す材料）。音は残さない。
- 声の数の決まり（1分に1回・5分まで）に対しては、**一連のやりとりで1回**として扱う（相づちは数えない）。

## 作り

- クラウド：`spirit_name.py` の `maybe_talk()` と `_talk_turn()`。呼び名を聞く仕組み（状態 `name_ask` の `phase`）をそのまま使い回す。
- **橋渡しは変更なし。**橋渡しは「`ask_name` が返ってきたら、鳴らす→聞く→送る」を繰り返すだけなので、会話でもそのまま動く。
- 記録：`talk`（話しかけた・文）／`talk_heard`（往復ごと：聞こえた文字・返した文・終わった理由）。

## 掲示

QR の先（`/spirit/notice`）を「話しかけるとき」に差し替え（1回の滞在に1度・十数秒聞く・返事があれば最大6往復3分・黙れば終わり・文字は残し音は残さない）。
**紙の手紙も同じ内容に差し替える**（本人）。

## 手元で確かめたこと（9/23）

- 相手が2回答えて黙る → 2回返して終わる。
- 相手がすぐ黙る → 何も返さずに終わる。
- 相手が話しつづける → 6往復目で静かに止まる。
- 同じ来訪で2回目は話しかけない。
