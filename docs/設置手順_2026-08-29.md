## 事前準備（家・研究室で）

## 設置日（キッチンで）

1. **置く**
   - 地霊C3：目に入る高さ。人感ドームは入口の動線に向ける。コンロ・炊飯器の蒸気・換気扇・直射日光はNG
   - 目WROVER：ゾーンを**斜め見下ろし**（真上はNG・AIの見間違いが増える）。逆光にしない
2. **電源を挿す**（2台とも）。TP-Link_C452には自動接続する
3. **動作確認（PCかスマホ・同じWiFiで）**
   ```
   python spirits/spirit_net.py find      → C3のIPが返る
   python spirits/spirit_net.py stat      → SRCがクラウド・Mが動いていればOK
   curl https://arigato-3ipecjbnha-an.a.run.app/spirit/full   → 目の写真が判断されているか
   ```
4. **カメラの向き調整**：`http://192.168.0.202/ui`（スマホ可）で首を振って構図決め
5. **最初の世話テスト（＝未実施の本流テスト）**：わざと物を置く→10分待つ→人感に手をかざしてから片づけて離れる→数分後 `stat` でCAREが増えれば研究ループ一周
