# 地霊システム 設置手順（2026-08-29）

夜のうちにソフトは全部仕上げ済み。残るは「同じネットワークに乗せる」ことだけ。
この順にやれば設置完了。所要 30〜60分（★1のMAC登録が要るかで変わる）。

## 構成のおさらい
```
目WROVER(192.168.0.202) ──同じTP-Link── 脳ラズパイ ──同じTP-Link── 地霊C3
        撮る                物体検出+AI判断(:8080)          顔と声
```
3台が同じTP-Link_C452に乗れば動く。

## ★1【最重要・唯一の関門】ラズパイをTP-Linkに繋ぐ

夜のうちに試したが**繋がらなかった**。電波は届く(信号70)・パスワードも正しい。
でも「association took too long」で弾かれる＝**TP-Link側でMACアドレス制限がかかっている疑いが濃厚**。
（目とC3のESP32は既に登録済みだから繋がる。ラズパイは新入りで弾かれている）

**ラズパイ wlan0 のMACアドレス: `d8:3a:dd:77:3a:b2`**

### 対処（どれか1つ）

**A. MAC制限を解除／このMACを許可（推奨・無料）**
- TP-Linkの管理画面（ブラウザで 192.168.0.1、ルーター底面のIDでログイン）
- 「アクセス制御」「MACフィルタリング」「デバイス管理」等の項目を確認
- 上のMAC `d8:3a:dd:77:3a:b2` を許可リストに追加、またはフィルタ自体をOFF
- 設定後、ラズパイは自動で繋がる（autoconnect設定済み）。数分待って ★1確認 へ

**B. 有線LANで繋ぐ（一番確実）**
- TP-LinkのLANポート → ラズパイに、USB有線LANアダプタ経由でケーブル1本
  （ラズパイの内蔵eth0は大学ネット/NASで使用中なので、USBアダプタで2本目の有線を足す）
- 有線ならMAC制限も電波も関係なく安定

**C. 電波を強くする**
- MAC制限でなく電波が原因なら、TP-Linkをラズパイに近づける／中継機を置く

### ★1確認（繋がったか）
PCから:
```
ssh kengk@133.27.17.28 "ip -4 addr show wlan0 | grep inet"
```
`inet 192.168.0.XX` が出れば成功。この **192.168.0.XX が脳のIP**。メモする。

## ★2 C3を「脳」に向ける

いまC3は目(192.168.0.202)を直接見ている。これを脳(上でメモしたIP:8080)に変える。

- C3をUSBでPCに繋ぐ
- `python spirits/spirit_ctl.py` で対話モード
- `src 192.168.0.XX 8080` と打つ（XXは★1でメモした脳のIP）
- `SRC 192.168.0.XX:8080` と返れば設定完了（電源を抜いても保存される）

## ★3 動作確認（3層の通し運転）

これが夜にできなかった唯一のこと。設置日が初の通し運転。

1. 脳が目を見えているか（PCから）:
   ```
   curl http://192.168.0.XX:8080/full
   ```
   `"eye_ok": true` `"src": "eye"` になっていれば、脳が本物の目を見ている（夜は false/cache だった）
2. `"objects"` に食器などが出ているか、`"score"` が妥当か確認
3. C3の表情：散らかっていれば `N` が育ってしょんぼり、きれいなら普段の顔

うまくいかない時の切り分け:
- 脳が目を見えない → 目(192.168.0.202)も同じTP-Linkにいるか確認
- C3が反応しない → `src` のIPが合っているか、C3がTP-Linkに繋がっているか

## ★4 物理設置（什器・電源・角度）

- **人感センサー(SR-602)**: 白いドームを露出させる（板の裏はNG・赤外線が透けない）。
  入口の動線に向ける。コンロ/炊飯器の蒸気/換気扇/直射日光に向けない
- **スピーカー**: 前に小穴を数個（塞ぐと音がこもる）
- **USB通し穴**: 3台分の給電ケーブル
- **電源**: USBアダプタ3個（目WROVERは2A以上・サーボがあるため）。電源タップ
- **カメラ角度（重要）**: 真上でなく**斜め見下ろし**にする。
  夜のテストで真上だと白皿を「sink」と誤読した。斜めにすると物体検出の精度が上がる
