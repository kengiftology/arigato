# 外れた見立て

**間違いで引くための索引。**本体は日々の記録（`research-os/secretary/logs/YYYY-MM-DD.md`）で、
ここはそこから抜いて**間違いの形で並べ直したもの**。食い違ったら日々の記録が正しい。

日付で並んだ記録は「同じ間違いをしかけている」ときに引けない。だから別に置く。
**当たった見立ては書かない。外れたものだけを書く。**
うまくいった話だけ残すと、同じ間違いがもう一度起きる。

**誰のものも落とさない。**進行役・各トーク・本人の区別なく載せる。
自分の外れが載らない索引は「他人の間違い帳」になって、誰も見なくなる。

## 読み方（2026-09-24 時点で見えている形）

**外れた見立ては、考え直して気づいたものが1つも無い。**
すべて **①測った ②別の人が見に行った ③実際に動かして壊れた** のどれかで分かっている。

| 気づき方 | 件数 | 例 |
|---|---|---|
| **測った・数え直した** | 7 | 模様と向き／声の422秒／案4／取り違えの余地 |
| **別の人が見に行った・数えた** | 6 | カメラの向き／336px／Wi-Fi と橋渡し／積もりの順番 |
| **動かして壊れた** | 3 | 固まった読み手／繋ぎ直しの暴走 |
| 突き合わせて発覚 | 1 | 時刻の45分のずれ |

**理屈や状況証拠で当てにいったものは、ほぼ外れている**（進行役の2件・B の模様・E の順番）。

**同じ間違いが、同じ日に3回起きている。**9/24 の進行役の3件（Wi-Fi・音割れ・錨）は、すべて
**状況証拠で原因を断じ、人が測って外れた**。**形が同じなら、間隔は1日もあかない。**
（3行にまとめず並べてあるのは、回数が見えるほうが効くため）

**手で決めた数字は古くなる。**20時間50分の停止の原因は、9/22 に手で決めた向きの補正 `dx=+0.12` が
そのまま残っていたこと（正しくは +0.07・写真上 274px のずれ）。
**いつから何pxずつずれたのかは、記録に残していないので追えない。**
→ **区画が3つになると、手で決めた数字が3倍に増える**（`ref`／`band`／`min_conf`／`pose`）。
**「この数字はいつ・どうやって決めたか」を、数字と一緒に残すこと。**

**もう1つ形が出ている：一度片づけたつもりのものが、片づいていない。**
- **訂正そのものが外れる**：9/22 の「336px は本当のずれではない」は訂正だったのに、実際にはずれていた
- **決まりが守られない**：「時刻を書く前に時計を読む」は、作ってから5日で3回破られた（書いた本人も含めて）

→ **訂正にも、決まりにも、同じ確かめが要る**（写真を見る・測る・突き合わせる）。
書いた時点では終わっていない。
1日ぶんでは言えないが、10日ぶん溜まれば考察に書ける形になるはず。

## 書き方の決まり

- **1行1件。**「見立て」は、外れる前の言い方をそのまま書く（あとから丸めない）
- **「どうやって気づいたか」を必ず埋める。**ここが空の行は、まだ調べ終わっていない
- **元の記録の日付を必ず添える。**本体は日々の記録で、これは索引
- 当たった見立ては書かない。**ただし「当たったが理由が違った」は書く**
- 追加は E（盤面と台帳）が行う。各トークは、外れに気づいたら進行役か E に1行送る
