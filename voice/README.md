# 地霊の声

キッチンを使う人たちの声を平均して、**誰の声でもない一つの声**を作る。

既製のキャラクターから声を借りるのではなく、その場所に関わる人の声から作る。
「場所がありがとうを言う」（主張台帳 #11）と筋を通すため。

---

## いちばん大事な決まり：あとから抜けられる

声を提供した人は、いつでも「やっぱりなしで」と言える。
そのために**人ごとにフォルダを分けて保管する**。

```
people/
  p_a/                 ← 1人ぶん。抜けたいと言われたら、このフォルダごと消す
    consent.md         ← いつ・どこまで同意をもらったか
    clips/*.wav        ← その人の声だけを切り出したもの
    embedding.npy      ← その人の声の特徴（128個ほどの数値）
  p_b/
  ...
spirit/
  embedding.npy        ← 全員の平均＝地霊の声
  made_from.txt        ← いま誰から作られているか
```

**抜ける手順は2つだけ。**

1. その人のフォルダを消す
2. `blend.py` を走らせ直す

数秒で終わる。**混ぜて学習させる方式（fine-tune）を採らなかったのは、この一点のため**で、
あちらだと1人抜けるたびに最初から学習し直しになる。

## 台帳との対応

- #11 感謝の主体を場所へ拡張 … 場所の声が、その場所を使う人たちからできている
- #6 人ごとに違う地霊 … 声色は聞き手ごとに変える（なつき度で切り替え）
- #12 第三者に伝えない … 声そのものからは誰の声か分からない（平均されている）

## 使うもの

- Python 3.11（`.venv`）
- PyTorch（CUDA版・RTX 2070 Super）
- 声の特徴を取り出すモデル（段階0で決める）

## 手順

| 段階 | 内容 | 人を呼ぶか |
|---|---|---|
| 0 | 環境構築と、公開音声で「中間の声ができるか」の検証 | 不要 |
| 1 | ゼミ録画から人ごとに切り出す（1人1分あれば足りる） | 同意のみ |
| 2 | 平均して地霊の声を作り、`/spirit/voice.pcm` に載せる | 不要 |
